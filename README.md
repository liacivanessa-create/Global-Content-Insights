Global Content Insights

Global Content Insights is an Excel data analysis project aims to analyse the relationship between IMDb ratings and viewership, along with exploring the content and the genre performance across countries using a dataset
collected from Kaggle, covering a period of time from 2016 to 2025.

The main objectives of the projects are the following:
Investigate the relationship between IMDb ratings and viewership
Compare the number of titles across the countries and genre performance
Examine average IMDb ratings by country
Present key findings through charts and an Excel dashboard

The dataset contains 200 titles across 10 columns. 
Of these, 142 titles had usable viewership values for the viewership analysis.

The tool utilised for the analysis is Excel where the following procedures have been applied:
Data Cleaning, pivot tables, descriptive statistics, correlation analysis, data visualisation, key findings, interpretations, limitations and dashboard built on 2 files:
Excel for the dashboard and pdf for the methodology.

Considering the key finding of the project, the correlation between IMDb rating and viewership is 0.0064 therefore indicating no linear relationship between the two variables in this dataset.
